# Release handoff

For every Head Room plugin version, add a versioned entry to CHANGELOG.md. Describe the user-visible changes since the previous version, using the labels people see in Orca. Mention what happens to existing profiles when relevant.

Give the maintainer a copy-ready Orca Cloud handoff in the chat every time. Include the version, minimum OrcaSlicer version, local upload and icon links, listing name, type, tags, full listing description, and the exact changelog from CHANGELOG.md. Include the GitHub commit, what was verified, and the next action for the public listing.
