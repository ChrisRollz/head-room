# Release handoff

CHANGELOG.md contains the exact text for the Orca Cloud Changelog field. For each release, prepend one plain-text paragraph. Start with the bare version, one space, then the user-visible changes on the same line. Put one blank line between versions and preserve the wording of earlier entries. Give the maintainer the full history, newest first, ready to paste.

Include the version, minimum OrcaSlicer version, local upload and icon links, listing name, type, tags, GitHub commit, what was verified, and the next action for the public listing.

## Orca Cloud description

Routine releases only need a changelog update. When the maintainer requests the listing description, use the text below verbatim. Formatting may change. If a release makes a wording change necessary, recommend the specific edit separately for the maintainer to consider.

Helmet Fitting for Cosplay. Make sizing cosplay helmets easier with Head Room. Create a personal reference head that stores your measurements directly in OrcaSlicer. For setup, a highlighted guide shows where to measure, and the 3D head reshapes as you enter each measurement. You can also import your own head STL. Save your head locally, reuse it for another project, or export it as an STL.
